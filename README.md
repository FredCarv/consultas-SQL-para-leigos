# Resumo
Esse repositório contém acesso para um guia básico e prático de consultas SQL para pessoas que trabalham com dados, mas não têm conhecimento sobre SQL.
Portanto, caso você trabalhe em uma empresa na qual exista um time de dados, mas nesse time existem pessoas que lidam com dados da maneira tradicional, seja via excel, power BI ou outros, esse material é de grande ajuda para elas começarem a utilizar SQL e potencializar o próprio trabalho.

## Guia de como usar
### Acesso simples
A forma mais simples e direta de acessar o guia é através do [Link](https://excalidraw.com/#json=EIOkNYC4MNxH3l5ugDhbr,Z_UEki_uYnvpdEZUUNuFmg)
Na pasta `conteudo para download/` você encontra o guia no formato PNG e também no formato .excalidraw, sendo Excalidraw o site utilizado para criar esse guia. Trata-se de um site voltado para criação de diagramas, onde não é necessário criar uma conta ou forncer seus dados para poder utilizá-lo, somente nas versões pagas, mas a gratuita já é ótima para seu uso no dia a dia e para acessar esse guia.
### Acesso editável
Na pasta `manual de uso/` você encontra um passo a passo caso queira abrir o arquivo .excalidraw no próprio site deles e editar o guia, caso queira fazer edições e complementar. Acesse o site do [Excalidraw](https://excalidraw.com/) e siga o passo a passo a partir daí.

## Atenção
* Esse guia foi criado pensando em queries SQL apenas a nível de consulta (DQL), ou seja, foi pensado apenas para que pessoas iniciando na linguagem SQL consigam apenas consultar e analisar dados, portanto não estou ensinando a manipular, alterar, criar ou deletar dados. Então, fique tranquilo caso você domine SQL e está pensando duas vezes antes de compartilhar com alguém que não sabe nada sobre a linguagem.
* A ideia desse guia é que, ao terminá-lo, o leitor já se sinta seguro para utilizar a linguagem, além de conseguir desenvolver consultas de níveis mais complexos com o auxílio de uma IA.
